# Landing Page — Web Development

Адаптивный одностраничный сайт-портфолио веб-разработчика.

- Тёмный дизайн с фиолетовыми акцентами
- Переключение языка EN / UA (выбор запоминается)
- Анимированные кнопки (ripple, блик, «магнитный» эффект)
- Анимации появления блоков, счётчики, слайдер отзывов
- Адаптивная вёрстка: десктоп, планшет, телефон

Чистый HTML, CSS и JavaScript — без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере.

## Деплой на Vercel

Import Project → выберите этот репозиторий → Framework Preset: **Other** → Deploy.
Настройки сборки не нужны.
